## Architecture Decisions (unchanged)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Frontend framework | Vanilla JS | No build step, instant deploy on Replit |
| State management | Global `state` object | Simple SPA, single source of truth |
| Real-time | Socket.IO | Bi-directional, room support built-in |
| Storage | In-memory | MVP speed; persistence is future work |
| AI integration | Anthropic streaming | Token-by-token UX for chat responses |
| Visualization | JSON → renderer functions | Decoupled agents from rendering logic |

---

## Known Limitations (carried from v0.3.0)

- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- Image agent is placeholder only
- No artifact versioning / undo
- Kanban drag is visual-only (no server-side reorder)
- No live cursors for multi-user canvas
- No export (PDF, PNG, etc.)
