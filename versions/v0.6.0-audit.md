## Feature Details

### InteractiveEngine (replaces InteractiveLayer)

Old: switch-case with 4 per-renderer handlers (mindmap, table, checklist, kanban visual-only).
New: generic engine reads data-attributes. 8 attribute types: `data-edit`, `data-edit-multiline`, `data-toggle`, `data-cycle`, `data-add`, `data-delete`, `data-drag-item`, `data-drag-target`.

All 15 renderers annotated. Adding interactivity to a new renderer = adding HTML attributes, zero JS.

### Mindmap Node Drag

- SVG mousedown/mousemove/mouseup on `.bs-mm-draggable` groups
- Client-to-SVG coordinate conversion via `createSVGPoint` + `getScreenCTM().inverse()`
- Lines update in real-time via `data-mm-line` selectors
- Positions stored as `_x`/`_y` on branch/child objects
- Renderer reads stored positions, falls back to angle-based layout

### Diagram Code Editor

- "Edit Code" button reveals `bs-code-overlay` with monospace textarea
- Save via button or Ctrl+S dispatches `bs-mermaid-save` custom event
- Engine catches event, emits `mermaid` patch
- Cancel or Escape closes overlay

### Artifact Expand Popup

- `#artifactExpandModal`: 90vw/85vh modal
- Header: icon + title + type badge + close
- Toolbar: AI Expand, Transform, Copy, PNG, Delete (always visible)
- Body: renderer draws at full size, add/delete buttons at higher opacity
- Ask bar at bottom
- InteractiveEngine attaches — all editing works in popup
- Real-time: `artifact-updated` refreshes open popup
- Open via: "Open" action button or dblclick on card header

### Brainstorm SDK (freeform/html_guide iframes)

- `BRAINSTORM_SDK_SCRIPT` injected into iframe srcdoc
- `window.brainstorm`: `markEditable()`, `edit()`, `add()`, `delete()`, `onUpdate()`, `getData()`
- Freeform agent systemPrompt documents SDK usage
- Engine forwards `artifact-updated` to iframe via postMessage

## Known Limitations

- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- Image agent is placeholder
- No artifact versioning / undo
- No live cursors for multi-user canvas
- Mindmap: no connection drawing between arbitrary nodes (only parent-child)
