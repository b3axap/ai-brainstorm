# AI Brainstorm — v0.4.0

**Date:** 2026-04-05
**Previous version:** v0.3.1
**Codename:** Chat-First Architecture

---

## Summary

Major rework of user-agent communication. Replaced rigid phase system with adaptive brainstorming partner behavior. Moved all interaction into chat (removed header button). Added per-user personal chats. Introduced visualization picker modal with multi-select.

---

## Changelog (since v0.3.1)

### Architecture: Per-User Personal Chats
- Each user in a room now has their own private conversation with Claude (`room.userChats[socketId]`)
- `claude-chunk` and `claude-done` events scoped to the originating socket only (not broadcast)
- Canvas and artifacts remain shared across all room users
- Other users see activity via `sidebar-message` event on canvas
- `send-message` event now stores messages in both personal and shared logs

### Architecture: Adaptive Chat (No Rigid Phases)
- **Removed** mandatory/free/mandatory_done phase system entirely
- **Single adaptive prompt**: Claude acts as a creative brainstorming partner
- Claude decides how many questions to ask (0-4) based on context, not a script
- Questions with clickable options only when there are obvious answer variants (yes/no, clear choices)
- Open-ended questions rendered without options — user always types freely
- Visualizations suggested when enough context has accumulated, not on a timer or counter
- Claude actively contributes ideas, plays devil's advocate, suggests alternatives

### UI: Chat-Only Interaction
- **Removed** "+ New Visualization" button from workspace header
- **Added** two action icons to chat input area:
  - 📎 (attach files — placeholder for future file upload)
  - ➕ (new idea mode — toggles green-bordered input, sends `isNewIdea` flag)
- New idea mode: Claude analyzes the additional idea, finds connections with existing brainstorm, suggests integration strategies + visualizations
- Empty canvas hint updated: "Chat with Claude to brainstorm — visualizations will appear here"

### UI: Visualization Picker Modal
- Full grid of all 15 agents with checkboxes, icons, and names (4-column layout)
- Multi-select — user can choose multiple visualizations at once
- Claude's suggestions pre-selected with purple highlight + "recommended" badge
- Custom visualization option: checkbox + text input → triggers freeform agent
- Reference existing artifacts section (shown when artifacts exist)
- "Generate Selected (N)" button with dynamic count
- Opened from chat's "Choose more visualizations..." button or canvas "+ New Idea" (removed)

### Socket Event Changes
- `send-message` now accepts `{ roomId, content, isNewIdea? }` — isNewIdea flag activates new-idea agent
- `claude-done` no longer includes `phase` field — all JSON fields are optional
- Added `sidebar-message` event for cross-user activity feed

### Documentation
- `CLAUDE.md` updated: adaptive chat behavior, chat input icons, new data flow, simplified event contract, removed phase tracking from data model

---

## JSON Response Format (new)

All fields optional — Claude includes only what's relevant:
```json
{
  "questions": [{"q": "...", "options": ["...", "..."]}, "open-ended question?"],
  "suggest": ["mindmap", "table"],
  "offer_canvas": true,
  "canvas_action": {"intent": "create", "artifact_type": "mindmap"}
}
```

---

## Breaking Changes
- `phase` field removed from `claude-done` event
- `mandatoryDone` / `mandatoryDoneAtMsg` removed from user phase tracking (only `msgCount` remains)
- `#newVizBtn` element removed from HTML — code referencing it will break

---

## Known Limitations (carried forward)
- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- File attachment (📎) is placeholder only
- Image agent is placeholder only
- No artifact versioning / undo
- No live cursors for multi-user canvas
- No export (PDF, PNG, etc.)
