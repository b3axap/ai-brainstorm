## Root cause analysis

The JSON regex bug (`[^{}]*` pattern) was the most impactful — it silently dropped all structured questions with nested options. Users saw plain text instead of clickable answer buttons whenever Claude included `"options": ["A", "B"]`.

The `response.content[0].text` crashes were latent — they'd only fire on empty Claude responses, but when they did, the server returned an unhandled error to all room users.
