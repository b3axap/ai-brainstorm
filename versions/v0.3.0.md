## Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Entrance animation | CSS keyframe, not JS | No JS overhead, GPU-accelerated |
| Z-index management | On mousedown, not hover | Prevents z-fighting during hover |
| Empty state | Static HTML, hidden by JS | No flicker, immediate display |
| Mobile touch target | 44px min-height | WCAG 2.1 AA target size guideline |

---

## Known Limitations (carried from v0.2.0)

- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- Image agent is placeholder only
- No artifact versioning / undo
- Kanban drag is visual-only (no server-side reorder)
- No live cursors for multi-user canvas
- No export (PDF, PNG, etc.)
