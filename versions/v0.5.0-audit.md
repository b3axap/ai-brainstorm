## Architecture Decisions (unchanged since v0.4.0)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Frontend | Vanilla JS, no build step | Instant deploy on Replit |
| State | Global `state` object in app.js | Simple SPA, single source of truth |
| Real-time | Socket.IO | Bi-directional, rooms built-in |
| Storage | In-memory | MVP speed; persistence is future |
| AI | Anthropic streaming | Token-by-token UX |
| Visualization | JSON -> renderer functions | Decoupled agents from rendering |
| Chat rendering | marked.js (CDN) | Markdown in assistant messages |
| Export | html2canvas (lazy CDN) | PNG screenshots of artifacts |
| Interactivity | Data-attribute protocol | Universal, no per-renderer handlers |

## Known Limitations (carried forward)

- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- Image agent is placeholder only
- No artifact versioning / undo
- No live cursors for multi-user canvas
- No artifact delete from canvas
- package.json version mismatch (0.3.0 vs actual 0.5.0)
