# Replit Prompt — AI Brainstorm v0.2.0 → v0.3.0

## Context

AI Brainstorm is a collaborative brainstorming web app. Users chat with Claude AI, then Claude generates visual artifacts (mind maps, tables, diagrams, SWOT, kanban, timelines, etc.) displayed on a shared canvas.

**Stack:** Node.js + Express + Socket.IO + Anthropic SDK. Vanilla JS frontend (no React, no build step). Dark theme with purple accents.

**Current state (v0.2.0):** Split-view workspace (chat left, canvas right), 15 visualization agents, interactive editing, structured chat flow, multi-user rooms. All in-memory, no persistence.

---

## What to do for v0.3.0

### Priority 1: UI Polish & Visual Consistency

1. **Align all artifact cards to design system** — ensure every card uses `--surface` bg, `--border` border, `--radius` (10px), `--shadow`. Check `renderers.js` and `style.css`.

2. **Improve mobile experience** — the bottom tab bar (chat/canvas switcher) on `<768px` needs clear active states, smooth transitions, and proper touch targets (min 44px).

3. **Canvas UX** — artifact cards should have:
   - Subtle entrance animation (fade-in + scale from 0.95)
   - Smooth drag (no jitter)
   - Z-index management (clicked card goes to top)
   - Empty state with illustration/prompt when no artifacts exist

4. **Chat UX improvements**:
   - Message bubbles: user (right, purple) and Claude (left, dark surface) — check alignment and padding
   - Typing indicator should pulse subtly
   - Clickable option buttons (from Claude's questions) need hover states and clear active feedback
   - Scroll-to-bottom on new messages

5. **Header polish** — user avatars should show colored initials, room code badge should be copyable on click

### Priority 2: Figma Integration Points

When you receive Figma updates (screenshots, design tokens, component specs), apply them to:

- `public/style.css` — CSS variables section at the top (lines 1-30). All design tokens live here.
- `public/index.html` — HTML structure. Keep it semantic, minimal divs.
- `public/renderers.js` — Artifact card styling. Each renderer returns DOM elements.
- `design.md` — Reference for visual specs, tokens, spacing, typography.

**Key CSS variables to check/update from Figma:**
```css
:root {
  --bg, --surface, --surface2, --surface3, --border
  --accent, --accent2, --green, --orange, --pink, --red, --blue
  --text, --text2
  --radius, --shadow
}
```

### Priority 3: GitHub Integration Points

When you receive code changes from GitHub, merge them into:

- `server.js` — Backend logic. Socket.IO events, Claude API calls, room management.
- `public/app.js` — Client state and Socket.IO handlers. Global `state` object.
- `public/interactive.js` — Inline editing (mindmap, table, checklist, kanban).
- `agents/*.json` — Agent definitions. Adding new agents = new JSON file + renderer.

**Key patterns to preserve:**
- Socket.IO event contract (see `versions/v0.2.0.md` for full event map)
- `renderArtifact(type, data, container)` entry point in renderers.js
- `InteractiveLayer` class wrapping artifact cards
- `buildContext(room, socketId)` for Claude API context
- Per-user chat phase tracking

## Do NOT change

- The Socket.IO event names and payload shapes (breaking change for connected clients)
- The agent JSON schema (`agents/_schema.json`)
- The `renderArtifact()` function signature
- The global `state` object structure in app.js
- Server binding to `0.0.0.0` (required for Replit)
