# AI Brainstorm — v0.2.0

**Date:** 2026-04-04
**Previous version:** v0.1.0
**Codename:** Split-View Workspace

---

## Summary

Major UX overhaul: the app now uses a split-view workspace layout (chat left, canvas right) instead of separate screens. Added interactive artifact editing, robust concurrency, and a structured 4-question chat flow.

---

## Changelog (cumulative since v0.1.0)

### UX / Layout
- **Split-view workspace**: CSS Grid layout `350px | 4px | 1fr` with draggable resize handle
- **Mobile responsive**: Bottom tab bar (`<768px`) switches between chat and canvas panels
- **Removed separate screens**: Chat and canvas are now simultaneous, not page-switches

### Chat System
- **Structured chat flow**: 4 mandatory discovery questions with clickable option buttons → free brainstorm mode
- **Per-user private chats** (`userChats[socketId]`): each user has their own conversation with Claude
- **Phase tracking**: `mandatoryDone`, `mandatoryDoneAtMsg`, `msgCount` per user
- **Canvas offer**: After mandatory questions, Claude offers to generate a visualization (one-time)
- **Canvas actions**: Claude detects intent and suggests `create`/`update`/`transform` actions as clickable buttons

### Artifacts & Canvas
- **Visualization picker modal**: 15 agent grid with search, icons, descriptions
- **Interactive editing** (`interactive.js`): Double-click to edit mindmap labels, table cells; click to toggle checklists; drag kanban cards
- **Action bar on hover**: Expand, Transform, Ask buttons per artifact card
- **Ask bar**: Mini input at bottom of each artifact for follow-up questions
- **@ mentions in chat**: Autocomplete dropdown referencing existing artifacts

### Backend / Robustness
- **Per-socket concurrency lock**: Only one Claude stream per user at a time
- **AbortController per stream**: In-flight calls aborted on disconnect
- **Reconnect handling**: Client auto-reconnects and re-joins room
- **Null guards**: Defensive checks throughout Socket.IO handlers
- **Duplicate user prevention**: `join-room` checks for existing socketId
- **Message cap**: Both shared and per-user histories capped at 200
- **Room cleanup**: 5-minute cancellable timer for empty rooms
- **Lazy Anthropic init**: SDK loaded on first use (avoids Replit crash without API key)

### Agent System
- **15 interpreter agents** loaded from `agents/*.json` at startup
- **Confidence scoring**: Hybrid system ranks agents by keyword match
- **Freeform fallback**: If no agent scores high, freeform HTML is used
- **Agent summaries API**: `GET /api/agents` returns list for picker modal

## Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Frontend framework | Vanilla JS | No build step, instant deploy on Replit |
| State management | Global `state` object | Simple SPA, single source of truth |
| Real-time | Socket.IO | Bi-directional, room support built-in |
| Storage | In-memory | MVP speed; persistence is future work |
| AI integration | Anthropic streaming | Token-by-token UX for chat responses |
| Visualization | JSON → renderer functions | Decoupled agents from rendering logic |

---

## Known Limitations

- No persistent storage (rooms lost on restart)
- No authentication (room code = access)
- Image agent is placeholder only
- No artifact versioning / undo
- Kanban drag is visual-only (no server-side reorder)
- No live cursors for multi-user canvas
- No export (PDF, PNG, etc.)

## Socket.IO Event Map

### Client → Server
| Event | Payload | Purpose |
|-------|---------|---------|
| `join-room` | `{roomId?, userName}` | Create/join room |
| `send-message` | `{roomId, content}` | Chat → Claude |
| `generate-artifact` | `{roomId, type, referenceIds?, customPrompt?}` | Viz picker → agent |
| `move-artifact` | `{roomId, artifactId, position}` | Drag artifact |
| `artifact-action` | `{roomId, artifactId, action, payload?}` | Expand/Transform/Ask |
| `artifact-data-patch` | `{roomId, artifactId, patch}` | Inline edit |
| `execute-canvas-action` | `{roomId, canvasAction}` | Confirm Claude suggestion |

### Server → Client
| Event | Payload | Purpose |
|-------|---------|---------|
| `room-joined` | `{room, user}` | Full state sync |
| `user-joined/left` | user info | Presence |
| `new-message` | `{message}` | Chat message |
| `claude-chunk` | `{chunk}` | Streaming token |
| `claude-done` | `{fullMessage, suggestedTypes, ...}` | Final response |
| `artifact-created` | `{artifact}` | New canvas item |
| `artifact-updated` | `{artifactId, data, title}` | Re-render |
| `artifact-moved` | `{artifactId, position}` | Sync position |
